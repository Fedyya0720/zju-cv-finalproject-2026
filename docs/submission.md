# 提交评测与排名规则

以下命令均在材料包根目录执行；示例中的“本组选择的别名”必须替换为实际别名。

## 准备预测图片

将预测结果保存为 `data/test/test_names.txt` 中列出的 20 个文件名，例如：

```text
predictions/
├── 000001.png
├── 000002.png
├── ...
└── 000020.png
```

目录必须**只包含这 20 张图片**，不包含说明、日志、子目录或其他文件。包中 `predictions/` 初始为空，可直接放入预测图片。
每张图片必须为 **768×432、8-bit RGB PNG**。不接受 JPEG、灰度、RGBA、16-bit 或符号链接；不自动缩放、裁剪、补图。
每张文件不超过 4 MiB，总提交不超过 32 MiB。

## 当前阶段：本地校验

本次先发布作业数据和协议，课程训练服务器账号与在线提交通道后续另行通知。
现在可以在自己的设备上开展实验、生成预测图并执行校验；不需要服务器账号、SSH、GPU 或额外 Python 包。
需要 Python 3.10+，在材料包根目录执行：

```bash
python3 submit.py --images ./predictions --alias "本组选择的别名" --check-only
```

把示例别名替换为本组实际别名。此命令只检查文件名单、PNG 格式、尺寸与大小，不上传、不绑定别名，也不计算 PSNR/SSIM/LPIPS（真值由助教保管）。

## 后续开通：在线提交

账号开通后，助教会另行提供账号、登录说明及连接配置。完成该配置后继续使用本包的数据、图片文件名和提交脚本。
以下以未来分配的账号 `cv26_001` 为例，届时替换为本组实际账号：

```bash
python3 submit.py --images ./predictions --alias "本组选择的别名" --user cv26_001
# 只上传、不等待
python3 submit.py --images ./predictions --alias "本组选择的别名" --user cv26_001 --no-wait
# 查询已经接收的任务
python3 submit.py --status 提交编号 --user cv26_001
```

在线提交需要 OpenSSH 和已开通的本组账号。**每次新提交都必须显式填写 alias**，不能省略、留空或使用占位符。
别名 2–32 个字符、全站唯一，首次有效提交被接收后永久绑定，之后只能使用原别名。
本地校验不绑定别名；任务被接收后，即使之后评测失败也不解除绑定。别名用于公开榜单，助教可查看账号对应关系。
上传被接收后返回 submission_id，关闭终端不会取消任务；保存编号以便查询。
每组同时最多一个排队或运行中的任务，两次接收至少间隔 5 分钟。查询既有任务不需要 alias。

## 评测与榜单

榜单：<http://10.76.5.255:8080/>，页面自动刷新。表格展示综合排名、alias、综合名次分，以及三项指标和各自排名。

- PSNR 越大越好：每张测试图单独算 PSNR，再对 20 张求算术平均。
- SSIM 越大越好：pytorch_msssim，11×11 Gaussian 窗口，sigma=1.5。
- LPIPS 越小越好：AlexNet，RGB / 255，normalize=True。
- 对完整 RGB 图像评测，没有前景掩码、曝光对齐或额外相机优化。
- 每组仅使用按接收时间确定的**最新成功提交**。新成功提交会替换旧结果，即使成绩变差；失败提交保留上一次成功结果。三项指标均来自同一次提交。
- PSNR、SSIM 从高到低分别排名，LPIPS 从低到高排名。单项同分取占用位置的平均名次，例如并列第 2、3 位均记为 2.5。
- **综合名次分 =（PSNR 排名 + SSIM 排名 + LPIPS 排名）/ 3**，三项权重各为 1/3，分数越低越靠前。
- 综合分相同则并列，名次按 1、1、3 的方式计算；并列组内仅按 alias 字典序稳定显示。
- 单项排名依据原始指标精度，综合排序使用未四舍五入的分数；网页显示四位小数。
- 新小组加入或某组更新成绩后，所有组的单项名次与综合分都会重新计算。
- 表格同时显示综合排名、综合名次分、三项指标数值及各自的单项名次。
- 如图片与真值完全一致，PSNR 可为 `Infinity`，这是数学上的正无穷。

评测版本及测试名单记录在 `tools/submission.json` 中。不要擅自替换测试划分或把其他版本的分数混入本榜。

## 常见问题

| 情况 | 处理 |
|---|---|
| 缺少 alias | 每次新提交补上 `--alias` |
| alias 已绑定/被占用 | 同组使用首次绑定的原别名；首次别名被其他组占用则另选 |
| 缺图/多图/尺寸或模式错误 | 对照 data/test/test_names.txt；移除额外文件，输出正确 RGB PNG |
| Permission denied / SSH 超时 | 先确认 `ssh cv2026` 能登录，以及校园网/VPN |
| 尚未开通提交权限 | 当前先完成本地实验和校验，等待账号与提交通道通知 |
| 本组已有待评测任务 | 等待原任务完成，按 submission_id 查询 |
| 超过频率限制 | 距离上一次接收满 5 分钟再提交 |
| 评测失败或等待超时 | 保存 submission_id 联系助教；已有成绩保留 |

可在解压目录执行 `sha256sum -c tools/checksums.sha256` 核对材料完整性。
